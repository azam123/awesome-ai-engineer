- Star badges are dynamic Shields.io badges, so they reflect the current public star count when rendered.
- Keywords summarize the likely domain and technologies; use each repository README as the source of truth for implementation details.
- Private repositories are clearly marked and may require access.

## Suggested Portfolio Highlights

For recruiters and engineering leaders, start with these repositories:

1. **Enterprise Document Intelligence** — enterprise document ingestion, secure retrieval, RAG, and agentic AI architecture on Azure.
2. **AI Solution Architect Assistant** (`GenerativeAISystemDesign`) — AI-assisted architecture workflow with a modern web frontend and .NET backend.
3. **ResumeIQ** — explainable resume intelligence and job matching.
4. **DevPilot** — reusable .NET developer utilities exposed through documented APIs.
5. **TokenWise** — token estimation, LLM cost calculation, and budget checks.
6. **Partner Integration Platform** — event-driven serverless integration with retries and dead-letter handling.
7. **GeoShield** — explainable geospatial risk screening.
8. **Awesome AI Engineer** — curated learning path for AI engineering and production GenAI.
